# Design Decisions

Ribo's design is captured as a numbered decision record (D1–D10): ESM-only, headless boundary, the
adapter model, zod at the boundaries, the `@azx/source` source-first dev loop, exact catalog pinning,
and more.

::: info Content coming
The D1–D10 decisions are repackaged here in the content pass. Contributors should start with
[Contributing](/design/contributing).
:::

The [Releasing](/design/releasing) page documents the versioning policy: independent Changesets
versioning, the 0.x semver rule (and what `1.0` will mean), and the `ribo-core` peer-range policy.
