# Introduction

Ribo is a reusable voice-capture SDK for field data collection. An auditor speaks their findings; Ribo
transcribes the dictation, extracts structured fields, lets a human review and accept them, and writes
the result back into a host tool through a thin per-tool adapter. The first target is home-energy
audits in Snugg Pro.
