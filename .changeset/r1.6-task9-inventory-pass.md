R1.6 Task 9 — the house-wide inventory pass

Adds the inventory-pass roster schema and instructions to the Snugg Pro adapter,
and a generic `extractInventory` phase to the OpenAI extractor. The roster lists
recordable candidate instances per collection group (`hvac`, `attic`, `wall`,
`window`, `dhw`) with the verbatim spans that ground existence, separation and
exclusion. The extraction phase makes one house-wide chat call constrained to the
roster schema and parses it at the trust boundary, with the transcript kept as
the last message so the injection boundary holds.
