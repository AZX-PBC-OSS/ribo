R1.6 Task 15 — instance grouping, add/remove affordance, and un-skipped tests

`useReview` now exposes `addInstance(group)` and `removeInstance(instancePath)`,
and keeps a local `extractedSnapshot` so the reviewer can add or remove collection
instances before submitting. Removing an instance re-keys decisions, errors and
link choices for the remaining instances so the data stays attached to the same
physical record.

`ReviewPanel` renders collection groups as labelled instance sections ("HVAC 1",
"HVAC 2", ...), derived from `parseFieldPath` rather than any Snugg-specific naming.
Each instance has a Remove button, and every collection group has an Add one/Add
another button. Empty-but-present collections render the group with an add
affordance so the reviewer sees the extraction noticed the absence.

The five tests owed by Task 15 are now un-skipped and passing: three in
`ReviewPanel.browser.test.tsx`, one in `extraction-ui.e2e.test.ts`, and one in
`network-transition.e2e.test.ts`.
