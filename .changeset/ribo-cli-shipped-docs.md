"@azx/ribo-cli": minor
---

Make `@azx/ribo-cli` workable from the installed tarball alone. The CLI's docs pages now ship inside the package (`docs/cli/`, a generated, drift-checked copy of the docs site's CLI section — the site sits behind a login), and the README and every command's `--help` name the installed pages first, the site URL second. Corpus and manifest enum refusals now name the allowed values and the value the file carried (`the field "provenance": expected one of real, synthetic, got "real-world"`). The shipped example corpus gains a document case (a one-page PDF with a text layer, its `capture` block and its expectations). `ribo eval`'s read of `--out` now skips files that are not run records — unparseable JSON, or JSON declaring no `contractVersion` — with one stderr line naming each, instead of refusing the run; a record-shaped file that fails the schema (a newer contract version included) is still refused exactly as before. The CLI's document transcription runs pdf.js at errors-only verbosity, so its harmless `Warning: …` lines no longer print; a genuine transcription failure still refuses the run. And `ribo schema inspect`'s granularity-violations line points at the shipped doc section that explains it.
