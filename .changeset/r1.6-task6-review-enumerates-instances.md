R1.6 Task 6 — review enumerates instances from data, leaves from schema

`buildReviewRequest` now walks `z.array(...)` groups by enumerating the data array
and recurring into the element schema once per instance. Each instance is assigned
a stable key (`k1`, `k2`, ...) and leaf paths are built with
`buildFieldPath(...)` so they read like `hvac[k1].hvacSystemEquipmentType`.

Order follows the emitted array order (first-mention); the key is what keeps a
review decision attached to the same instance across add/remove operations later.

Empty-but-present collections produce no leaf paths and are recorded in the new
`ReviewRequest.presentButEmpty` array. A group absent from the extraction output
is not recorded there, preserving the distinction between "create none" (`[]`)
and "touch nothing" (key absent) for Task 7.
