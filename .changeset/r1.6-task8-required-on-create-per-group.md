R1.6 Task 8 — `requiredOnCreate` becomes per-group

`ToolAdapter.requiredOnCreate` is now a `RequiredOnCreate` record keyed by group,
where each value is the list of leaf names required to create one record of that
group. A collection group with N instances therefore marks N × those leaves as
required, without the adapter enumerating instance-keyed paths that only exist
after extraction.

`buildReviewRequest` applies the declaration to every instance of a named group
as it walks the values schema. Singleton groups are unaffected: a declared singleton
group still marks its named leaves, and undeclared groups mark none.
