R1.6 Task 16 — the instance-modeling strategy ladder

Adds the three-tier extraction ladder composed through `fallbackExtractor`:

- Tier 1: `scopedInstanceExtractor` (house-wide inventory pass followed by scoped
  per-instance fills).
- Tier 2: `perGroupArrayExtractor` (per-group calls, model emits an array for each
  collection group).
- Tier 3: `perGroupSingletonExtractor` (per-group calls, model emits a flat singleton
  per collection group, wrapped back to a one-element array).

`instanceLadder(options)` wires the three tiers together and stamps the accepted
strategy name onto `result.usage.strategy`. The host supplies the arbiter, so the
choice to accept a degraded Tier 3 result at exhaustion is a host policy, not an
SDK invariant.

`perGroupExtractor` gains a `singleton` option that narrows collection groups to one
element per call and wraps the parsed singleton back into a one-element array so the
result still validates against the original extraction schema.
