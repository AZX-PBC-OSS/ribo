R1.6 Task 10 — scoped per-instance fills and assembly

Adds a `scopedInstanceExtractor` to the OpenAI extractor: one house-wide
inventory call followed by one fill call per `current` candidate, with the
results assembled into their group arrays in roster order. The fill call's
response schema is a single flat group object, so segmentation cannot change
after the inventory pass. A scope block inserted before the transcript names
the positive record, the negative siblings whose facts belong elsewhere, and
any excluded candidates, so the model can route `null` correctly instead of
mixing values across instances. The Snugg Pro adapter gains
`snuggGroupFillInstructions` to render the scope block in its natural-language
rules, and the few-shot example now carries a second HVAC system to teach the
array shape.
