R1.6 Task 4 — `clampDeep` no longer destroys arrays when normalizing extraction output.

`normalizeFields`'s recursive walk previously rebuilt every object with
`Object.fromEntries(Object.entries(node))`. On an array that produces an object
whose keys are numeric strings (`{"0": {x}}` instead of `[{x}]`), which would
corrupt every collection group the moment the schema becomes an array. The walk
now maps over arrays and recurses into each element, so element order is
preserved and confidence clamping still reaches inside every instance. Empty
collections stay empty arrays; no placeholder instance is inserted (R1.6 pinned
decision 2).
