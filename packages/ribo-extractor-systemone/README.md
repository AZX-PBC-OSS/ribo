# @azx/ribo-extractor-systemone

System One-backed extraction strategies for Ribo.

Scaffolded and mostly empty on purpose: later tasks fill in a verification combinator and an
extraction phase over [`@azx/ribo-systemone-managed`](../ribo-systemone-managed/README.md)'s
client. It currently exports `enumMembersAt` — the schema walk those will build on, answering
"what enum members may this leaf hold?" for a leaf of an extraction schema.
