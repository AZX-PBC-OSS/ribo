On-device extraction — corpus run

Runs the annotated transcripts through the real on-device model, one extraction each, and writes results where score.mjs reads them.

Must be opened in real Chrome. Chromium's Prompt API is a stub that answers with fixed text, so a run there would grade nothing. This page checks and refuses.

Each extraction makes seven calls and roughly half of them degenerate and retry, so expect a few minutes. Leave the tab focused — a background tab gets throttled.
